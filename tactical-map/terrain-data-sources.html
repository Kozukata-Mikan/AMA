地形生成の資料と精度

地形だけを生成します。地理生成の北は−Y、東は＋Xです。XYは1格200m、Zは1格100mで換算します。最大14401×14401格の範囲を維持し、生成時の標高・海岸線は適応間隔でサンプリングします。編集グリッドと元資料の精度は異なります。

海岸線

Made with Natural Earth 1:10m Land v5.1.1。Public domain。元ポリゴンを0.002度の許容差で概略化し、1/10000度に量子化しています。小島や細い海峡、沿岸の形状は実物と異なる場合があります。利用条件。

陸地の高さと海底

オンライン高程は Mapzen / Tilezen Terrain Tiles のTerrarium画像から取得します。近似山地は地理上の高さを再現するものではありません。平坦モードは陸地を10mに設定します。海底は全モードで指定した一様な仮の深さを使い、実測水深は取り込みません。

生成間隔、資料の解像度、局所投影と海岸線の一般化により誤差があります。高さ取得に失敗した際に推測地形へ自動で切り替えることはありません。低地の海岸線と高程資料の不一致部は、海陸マスクを優先し陸地を最低1mとします。河川・湖沼の現実データはこの版の地理生成には含みません。

高程は同時取得4枚・1回最大16枚のタイルから概略生成します。大域では中心緯度を基準とする局所投影を使用し、離れるほど距離と形に誤差が生じます。中心緯度±75度、範囲端±80度まで対応します。

地名検索

Open-Meteo Geocoding API / GeoNames。プリセット以外を検索する場合のみ入力した地名をサービスへ送信します。戦役データ・ユニット・図鑑は送信しません。座標を直接入力すれば検索は不要です。都市以外の島・海域などは検索できない場合があります。サービス利用条件。
