# AMA 地形预览与浏览器回合基线

本目录的入口独立于 AMA 首页。原版仍从项目根目录的 index.html 进入。地形预览与原版使用同一个 tactical-map/terrain-data.js 地形校验和取样实现。预览只读入用户选择的文件，不访问 AMA 的浏览器存档。

## 生成可分发的预览

在 prototype/terrain 执行 npm ci 和 npm run build。将 dist/AMA-Terrain.html 和 node_modules/three/LICENSE 一起分发。HTML 包含渲染器，无需服务器即可打开，也可以直接放到静态网站上。三维视图需要 WebGL 2；二维参照图可以单独使用。

拖动旋转、右键平移、滚轮缩放。点二维图即可移动相机。全图使用粗网格，靠近后细化为每格一根地形柱。水面位于零高程，选中地格时显示原始地形高程（含负值）。垂直夸张影响显示高度。示例港址是预览标记；导入作战场景时，港口按钮定位到场景里的第一座港口。

在原版作战编辑器中使用「JSON 書き出し」导出作战数据，再在地形预览中选择该文件。也可导入原版 v1/v2/v3 地形对象。此版本沿用原版地图范围；14401 格和可破坏地形属于后续阶段。

## 复现浏览器基线

1. 在项目根目录启动本地静态服务器，例如 python3 -m http.server 8908 --bind 127.0.0.1。
2. 在 prototype/baseline 执行 npm ci。
3. 指定 CHROME_PATH 为本机 Chrome 或 Chromium 可执行文件，然后执行 npm start。可用 AMA_URL 指定服务器地址，用 RESULT 指定输出 JSON 的路径。若指定 PROFILE，请使用专用测试目录。
4. 对照 baseline/results.json 的逐回合原始记录。ms 为整回合耗时，writeMs 为主页面内 IndexedDB 写事务从创建至完成的累计时间，bytes 为实际读回的序列化存档 UTF-8 字节数，reopenMs 为新页面打开推演到读出场景的时间。

样本为海面上双方各 100 艘静止、未装备武器的测试舰。驱动程序使用浏览器中的推演接口推进完整回合，在 1、10、25、50、100 回合结束后关闭页面并重新读取存档，核对回合号，继续推进到 101 回合。回合数据用于比较历史增长及持久化成本，未计入前端面板绘制或玩家操作时间。

完成预览构建并启动静态服务器后，设置 CHROME_PATH 并执行 node prototype/baseline/verify-entries.mjs，可重跑首页到作战编辑器、预览 HTTP 入口和断网 file 入口的操作检查。脚本在临时浏览器配置中检查场景导入、坐标高程读取、港址定位和垂直夸张控制。

## 地表编辑与工程文件

在二维或三维视图选点，选择笔刷和半径，点击「应用到选区」。可设置草地、林地、岩地、雪地、沙漠或沙滩，或把所选圆内的地格整体升降 100 米。地格降到零高程时显示为水面。地表配色会根据旧地图的高度和水系生成，沙漠等需要指定的区域可以手动绘制。「恢复自动地表」可清除材质覆盖。「撤销」可回退本次编辑中最近 50 次操作。

「导出地形工程」将底图、港址标记和逐格修改一起保存，下次用同一个导入按钮打开。此文件用于预览器，作战单位及推演历史仍保存在原版场景。运行 node --test prototype/terrain/surface.test.js 可检查笔刷范围、海岸变化、图层往返和边界地格。

## 14401 × 14401 格地图验证

「打开 14401 × 14401 大地图」使用内置岛屿作为低分辨率底图，并将它映射到整个新范围。单格中心的整数坐标从 −7200 到 7200，X/Y 定位可以直接跳到边角。局部地形编辑以独立格号存储，导出工程包含底图和改动过的格子。浏览器推演与旧场景仍使用原有地图格式及尺寸校验。

## 正式推演与桌面程序

本分支的作战编辑器、地图生成器和推演共用 14401 格的边长上限；单格精度对应每边 14402 个顶点。推演页的「3D 地形」可打开当前观察视角。大破水面舰发出黑烟，状态随存档恢复。范围事件触及陆地时，每个符合范围的地形顶点降低一个高度单位，最低降至海平面。结算事务统一写入地形、单位状态与阶段，初始部署另行保留。

桌面入口使用独立的 ama://game 源和当前系统用户的 AMA-Desktop 存储目录。浏览器和桌面端共用作战代码，以完整推演存档 JSON 转移进度。重新构建三维视图时，在 prototype/terrain 运行 npm ci 及 npm run build，构建会同时更新网页和桌面使用的 tactical-map/terrain-3d.html。

Windows x64 使用官方 Electron 45.5.0 压缩包。运行 python prototype/desktop/package.py electron-v45.5.0-win32-x64.zip AMA-Windows-x64.zip。脚本验证运行时 SHA-256，并要求输出文件名尚未使用。原生 Windows 验证流程见 .github/workflows/desktop-windows.yml，包含两次独立程序启动、恢复单位位置与阶段、检查大破黑烟和三维窗口。
