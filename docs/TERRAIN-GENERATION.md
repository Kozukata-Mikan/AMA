# 地形自动生成

自定义页面的“地図と地形 → 地形の自動生成”提供两种方式。只生成地形，不生成建筑、港口或道路。

## 描述生成

中文、日文、英文的地形关键词由本地解析器转为参数，不使用外部大模型或密钥。支持山脉、丘陵、岛屿、群岛、平原、海域、海岸、河川、山谷；数字长度以km/公里/千米/キロ识别，高度可用m/米/メートル等。无法识别时明确报错。可手动调整地形种类、长度、高度、方向、地图范围、海底深度、种子和精度。

例：“我想要生成一片连绵10km左右的山脉”。最小地图范围沿用原规则120格＝24km；10km为山脉本身的长度，不把它放大到整张地图。

## 现实地区

海岸线来自本地打包的Natural Earth 1:10m Land v5.1.1公共领域数据，简化容差0.002度。预设宿务及周边、冲绳、台湾、对马、夏威夷，亦可使用Open-Meteo/GeoNames搜索地名并选择候选，或者直接输入中心经纬度。搜索不能找到所有岛屿或海域，不静默改用其他地方。

XY每格200m，Z每格100m。使用中心纬度的局部等距近似投影；北为−Y、东为＋X。最大7200×7200格（1440×1440km）。中心纬度±75度、地图边界±80度，极区不支持。跨日界线的海岸线按平移经度处理。

陆地可选在线高程、近似山地、平坦。在线高程按Terrarium格式读取Mapzen/Tilezen的公开高程瓦片，最多16张、并发4张，不把网络失败静默替换成推测地形。近似山地明确标为推测。海底始终为用户指定的一样深度，没有冒充真实水深。现实河流、湖泊和建筑等不包含在这版地理生成中。

## 编辑与保存

生成在模块Worker内运行；返回独立的v3地形预览，应用前不修改存档。用户确认后通过现有原子保存路径替换地形，并记录结构撤销帧。单位坐标保持原值，由现有规则重新校验部署。生成和原图身份绑定，外部换图、重置、销毁会使旧预览失效；设置变动也需要重新生成。

生成地形的基础网格上限为257或513个采样点/边，不为7200×7200格逐格预先分配；编辑网格仍为每格200m，未修改处按完整基础地形三角面插值。预览会显示实际生成间隔，范围越大间隔越大，细小岛屿和狭窄海峡可能省略。生成来源、种子、高程模式、中心坐标和生成间隔随地形保存。旧v1/v2/v3存档兼容。

## 数据构建

官方源：[Natural Earth Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)。下载ne_10m_land.zip后：

```
python -m pip install shapely pyshp
python scripts/build-terrain-coast.py /path/ne_10m_land.zip data/terrain-land.b64
```

打包格式为经纬度整数的环坐标差分，gzip后base64；生成界面按需加载，普通地图和推演不会预先下载。原压缩包SHA256随数据保存，构建脚本使用确定性gzip时间戳。来源和许可列于tactical-map/terrain-data-sources.html。

## 验证

`node --test tests/*.test.mjs` 包含描述解析、各类地形确定性、最大7200格范围、洞和日界线、宿务实际海陆轮廓、瓦片预算与解码、真实线程异步生成协议，以及预览不写入、应用、撤销重做、存档重开和预览失效等检查。在线高程与真实浏览器操作另作部署后验证。
