# 発煙筒・探照灯・艦橋／中心

2026-11-27。既存の砲戦・航空・保存・バックグラウンド結算を維持して接続。

## 規則

- 発煙筒：特殊段階に継続ON/OFF。毎ラウンド1組消費。次回の実移動経路へ幅1マス・地形／海面上10マスの煙幕を残す。次の特殊段階処理で消え、継続ONなら新しい1組を使用する。
- 停止・転針を反映。OFF・設備損傷でも発生済み煙幕は残る。未使用組がなければ新規発煙しない。
- 双方の三次元偵察視線を遮蔽。必見100マスと保持発見にも適用。高い視線・完全に水面下の対潜視線は通る。
- 煙幕は線分と半径0.5のカプセルとの厳密な交差で判定。地形三角形・海岸の高さ切替を考慮。空間バケットと状態番号付きキャッシュで無関係な経路の検査を抑える。
- 近くの煙幕は環境として表示するが、未識別の発煙元は公開しない。敵の遠方の煙幕経路は観察副本へ含めない。
- 探照灯：1組につき識別済み1目標。水平100マス。開始・特殊段階に設定し、消灯・切替・距離超過・設備停止まで継続。消耗しない。
- 照射元と目標へ向けられた攻撃の黒夜ペナルティを解除。黎明・夕焼・天候・射距などは維持。射撃側が照らされただけでは暗い別目標へのペナルティは消えない。
- 艦橋：対海・対空・対潜偵察と追加支援を収容。設備威力は六部位＋艦橋の7項目を等確率抽選し、艦橋内機能をまとめて損傷。既存の保持発見・損管成功／完全破損を継承。艦砲の六部位命中は変更しない。
- 建築中心：三種の偵察と複数の支援配置を収容。中心は耐性1区画で、追加支援行で中心耐性を分割しない。中心停止で全建築停止、恒久建築の再建規則を維持。

## 互換性・保存

- 旧8項目の設備状態を7項目へ移行。完全破損と当ラウンドの保持発見を保持する。
- 旧8項目の過去の抽選報告はバージョン1としてそのまま検証する。新7項目の抽選報告はバージョン2。
- 継続中の旧偵察修復任務を艦橋へ移行。完了済みの旧報告と初期場面は書き換えない。
- 煙幕経路・消費済み組・発煙継続設定・照射目標は完全推演セーブに含む。
- 新しい支援装備は図鑑へ重複追加せず補完し、ユーザーの既存編集を維持する。
