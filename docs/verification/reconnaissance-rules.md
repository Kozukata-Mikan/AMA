# AMA 当前侦察规则核对（2026-11-25）

以下按实际执行代码核对，不把图鉴字段或旧规则书里的构想当作已实现功能。本次只整理侦察现状，不改侦察算法。

## 距离、等级与识别

- 侦察距离是XY平面直线距离，不包含高度差与潜深；1格为200米。
- 普通侦察范围 = 400 − 时间减值 − 天气减值（代码下限0；现有环境组合实际最小100）。400格约80公里。
- 时间：白昼05:30—19:00减0；黎明04:00—05:29与夕烧19:01—20:30减50；黑夜20:31—03:59减100。
- 天气：白色晴天减0；蓝色阴天／小雨／小雪减50；黄色雾／雷雨／大雨／大雪减100；黄色高温、结冰不减；橙色浓雾／暴雨／暴雪／海潮与红色台风减200。
- 距离≤100格时，无视侦察等级与环境减值而直接识别，但仍要通过地形遮挡；潜航目标另需有效对潜侦察等级。
- 距离>100且在普通范围内时，侦察等级≥目标探测难度则发现为“影”，否则看不到。等级顺序F<E<D<C<B<A<S<U。不是掷硬币或逐回合概率判定。
- 当前侦察等级读取只认以上基础字母；C+等带修饰的文本不会自动折算。
- 远程的“影”不会随回合数自动升级为识别；多个单位同时发现也不会把等级相加。任意己方有效来源识别后，整个阵营共享识别结果。

## 对海、对空、对潜

| 目标 | 读取观察者字段 | 特殊条件 |
|---|---|---|
| 水面舰、深度0的水下舰、陆上舰（海军模板）及建筑 | 对海侦察 | 近距识别／远程影规则 |
| 航空机、空中舰 | 对空侦察 | 相对目标所在地形／水面高度≤10时，100格之外的普通对空侦察无效 |
| 深度≥1的水下舰 | 对潜侦察 | 必须填有效对潜等级，100格内也不能以对海侦察替代 |

- 海军、建筑、航空机使用共同的等级与距离规则。水下舰自身也以目标种类决定使用对海／对空／对潜字段。
- 低空规则对所有空中单位生效，不需要装备“游云”。游云负责接近目标100格以内时自动转到地形／水面上方1格；地形高度10时，实际高度20仍属于相对高度10。
- 当前没有潜深越深越难发现的系数、最大声呐探测深度、主动／被动声呐、独立雷达探测算法或机体体型侦察修正。
- 夜间观测解除航空时间限制，不取消夜间侦察距离减值，也不自动增加侦察等级。

## 地形与单位状态

- 两点间XY直线穿过真实地形高度≥30的区域会被遮挡；同XY位置不被沿途地形遮挡。
- 使用真实地形三角面，而非显示用的抽样地形。端点刚好30而其后立即下降时，端点本身不算障碍；端点>30也会遮挡。
- 这不是按观察者眼高、飞机高度绘制的三维视线；飞机即使高于山，也仍受这条统一地形高度门槛影响。
- 濒沉／沉没舰、救助锁定的舰、基地作业中的空中舰不能提供正常侦察；建筑中心失效后不能提供侦察。
- 航空机必须在空中且未大破／被摧毁才能作为侦察来源。大破机只能移动；混乱或撤退中的未大破机仍可侦察。
- 敌方驻机／整备／起飞等待中的飞机不作为独立空中目标显示；己方始终可查看自己的驻机状态。

## 共享视野、显示与攻击

- 当前按所选观察阵营合并所有有效来源，取最佳可见性；开启敌方自律时观察视角固定为我方。
- 影保留XY位置与可见火焰，但隐藏真实名称、阵营、军种、耐性、装备及编队资料。
- 已识别敌人可查看公开资料，但不公开内部弹药、航线、机队恐慌等己方专属状态。
- 常规攻击、CAS、CAP自动交战和护航等都需识别目标；单凭远处一个影不能直接当作已识别目标登记攻击。
- 雷达引导除阵营识别外，还要求发射单位自己至少发现该目标；自己发现为影可以，自己完全看不到不行。数控不额外要求发射者单独发现，但也不绕过阵营识别。射线锁定是另一个攻击限制，不是扩大侦察范围的功能。
- CAR主动规避对100格内已识别的敌机／空中舰作出返航反应。CAP与护航的敌机选择也受当前可见性限制。
- 不存在通用的永久发现记忆；失去有效来源后会重新变为影或不可见。回合战斗记录保存的是当时自身视角，不等于保留实时识别。

## 设备损伤：已接通与缺口

- 对海侦察损坏后，海军对海军的观察路径不再产生新发现；受损前发现仅在受损当回合保留，下回合失效。其他己方来源仍可提供视野。
- 这条损坏钩子按“观察者／目标均属海军”挂接，因此对空中舰目标也可能受到该钩子影响；对建筑／航空机目标并非全部采用同一损伤钩子。这是现有适配的粒度限制。
- 对空侦察存在设备损伤项，但设备定点攻击的对空侦察来源适配仍返回空；不能把这部分当作已完成。
- 对潜侦察没有完整独立设备损伤项。目前三类侦察还未做到所有军种与目标路径上的一致损伤处理。
- 陆军、特殊单位的远程等级侦察尚无完整规则，近距共同识别路径仍存在。
