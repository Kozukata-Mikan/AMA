# 大型慣性・電子戦・フレアの検証

2026-11-27。既存の推演保存・バックグラウンド結算に接続。UI・規則書は日本語。

## 接続内容

- 通常慣性は空中艦に対して有効。艦の強度装甲を使用する。数字威力・艦砲威力を実結算で確認。
- 大型慣性は座標指定のみ。完全投射量を持つ独立弾体1体を生成し、次ラウンドの同一次序に着弾。
- 弾体：装甲0・探測難度E・高度200～300・耐性＝穿深の爆発半径。耐性0は不発。
- 通常対空射撃による迎撃に対応。着弾する次序の迎撃も着弾より先に処理する。発射艦喪失で弾体は消えない。落点固定で、目標の移動に追従しない。
- 電子戦ポッド1組5点、水平半径750マス。対象位置に届く攻防を合算。双方同時圧制に対応。
- 各組の攻防設定は開始段階に選択し、移動に入ると本ラウンドを固定。初期は防御。同ラウンド中の兼用は不可。
- 20点差：通常偵察無効・干渉源探測難度E・強ロック。従来の100マス必見と地形遮蔽は維持。
- 30点差：レーダー誘導の束内硬貨50%、無人機攻撃不能。数値制御はこの50%変更の対象外。
- 40点差：対海・対空偵察E、飛行・着陸中の無人機を特殊段階で100%喪失。20点差の偵察無効も累積。
- 50点差：敵探測難度E、干渉源自身の等級低下解除。元の図鑑スナップショットは維持。
- 強ロック中は機動硬貨0枚（練度固定表も0枚）・フレア使用不可。
- フレア：自動ON、手動OFF可。1組消費、1ユニット1ラウンド1回。発動した単一の次序のレーダー・数値制御攻撃を全て無効化。
- 発射・迎撃・着弾・電子設定・消耗状態は完全推演セーブに保持。自陣営以外の電子設定・消耗履歴・弾体発射元は観察副本から除く。

## 継続する既存境界

- 通常慣性の航空機固有強度防御、および大型武器を含む掛載誘爆の専用裁定は今回新定義しない。
- 大型慣性の自律座標選定は実装せず、手動指定された発射のみ行う。自律ユニットが大型武器を持つだけで次序を中断しない。
- 表示弾道は発射点・高空の弾体・固定落点を結ぶ模式表示。物理弾道シミュレーターではない。
