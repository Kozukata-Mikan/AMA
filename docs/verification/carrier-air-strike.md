# AMA：机场对航母小舰队联合规则验收

> 下文基线是地对空上线时的规则。2026-11-25新增迷航／迫降规则后的复算附于文末，最新脚本会输出新规则结果。

这是为验证程序而新建的合成单位场景，不使用玩家图鉴，不代表历史舰机或战斗平衡结论。
固定随机种子：`20261125`。连续两次独立计算，伤亡、舰船耐性、扰乱事件与交战次数完全一致。
执行真实整备、跑道起飞、航路移动、攻击、特殊阶段、回合结束与IndexedDB存取；每回合从存档重新打开。Node测试环境使用正式后台任务的兼容执行路径，而非浏览器实测帧率。

## 新增扰乱规则

每次序合并舰船／建筑对同一航空集群的合格投射：`新增惩罚 = floor(总投射 ÷ 该次序开始时集群生存机数 ÷ 10)`。命中为0也生效；同次序与本回合后续攻击均受影响；各次序新增值相加，次回合读取为0。次序内先汇总全部有效投射再掷命中骰，所以不受计划排列先后影响。
按现有命中机制抵消奖励并限制有效惩罚轮数；独立R保留既有规则，不强行更改。端数不跨次序累计。集群拆分后，已经获得的惩罚跟随各机保留；后续防空按实际目标集群重新计算。

本次另行修正：普通次序的地对空资格；舰船对正上方航空目标的射界；同次序地对空先击坠空战目标时，已经按阶段开始状态验证过的空战不会重新验证死目标而回滚整个阶段。
验证覆盖本场景与固定种子，不能据此保证所有玩家图鉴、武器组合及大型场景都没有边界问题。未定义的大型武器、设备威力和航空机惯性防御仍会明确拒绝，未用普通伤害冒充。
